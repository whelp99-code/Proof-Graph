# ProofGraph v0.9.0 — Graph Debugger and Inspector

v0.9.0 adds an operator-grade debugger and read-only visual inspector to the Graph Engineering runtime.

## Delivered

- Persistent, digest-protected per-run debugger state
- Pause, resume, single-step, node breakpoints, kind breakpoints, and one-shot breakpoint bypass
- Kernel-aware pause semantics that never convert a debugger stop into an agent failure
- Verified graph, edge, failure, route, event, workspace, and integrity inspection
- Text, JSON, Graphviz DOT, and token-protected loopback HTTP inspector surfaces
- Fail-closed detection of debugger-state tampering
- CLI commands: `debug`, `inspect`, and `serve`

## Safety boundaries

- The inspector binds to loopback unless explicitly overridden.
- The HTTP surface uses a random bearer token and no-store responses.
- Debugging does not permit arbitrary state rewind or node-result rewriting.
- Breakpoints stop before an adapter is invoked; step mode permits one node and pauses before the next.
- Workspace and graph integrity remain independently verified.

## Verification

- Full automated suite: 126/126 PASS at release commit.
- Added dedicated debugger, inspector, HTTP authorization, loopback, DOT reconstruction, and state-tampering tests.
