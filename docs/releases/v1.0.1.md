# ProofGraph v1.0.1 — AI Agent TUI GraphSpec integration

v1.0.1 is a patch release that demonstrates how a concrete software request is converted into a reviewed and executable graph.

## Added

- `agent-tui` built-in template and typo-tolerant Korean natural-language matching
- JSON-based GraphSpec v1 schema and bilingual documentation
- reviewed `examples/graphs/ai-agent-tui.graph.json`
- explicit GraphSpec CLI: validate, start, run
- explicit GraphSpec universal MCP tools
- dependency-free interactive `proofgraph tui` and non-TTY snapshot mode
- bounded pause, resume, single-step, approve, deny, and abort controls
- functional, adversarial, integration, and independent black-box verification
