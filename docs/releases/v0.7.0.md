# ProofGraph v0.7.0 — Universal Adapter Layer

## Delivered

- One typed `AgentRequest` / `AgentResult` contract across coding-agent CLIs.
- Shell-free subprocess supervision with timeout, abort, stdout/stderr limits, and environment scrubbing.
- Vendor-envelope parsing for JSON, JSONL, fenced JSON, and nested result messages.
- Built-in profiles for Claude Code, Codex, OpenCode, Grok Build, and Pi.
- Strict Pi JSONL-RPC client that waits for the host settlement contract and rejects interactive UI requests.
- Gajae Code v0.11 safety posture: external `--mode rpc`, `rpc-ui`, and `bridge` CLI ingress is not used; a pinned SDK v3 WebSocket bridge or explicit trusted command profile is required.
- `proofgraph adapters` doctor output and `proofgraph adapter-config` example.
- Mock remains the safe default; every live adapter must be explicitly enabled.

## Safety boundary

OpenCode, Grok, and Pi may expose host mutation tools. ProofGraph refuses to invoke these profiles outside an isolated workspace unless the operator explicitly opts into host-tool access. Claude and Codex profiles are launched in read-only/plan modes, but still require live canary validation against the installed CLI version.
