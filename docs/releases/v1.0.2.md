# v1.0.2 — Orca execution-host compatibility bridge

## Added

- Orca CLI execution host and adapter
- Graph Node → Orca Task/Worktree/Terminal/Dispatch mapping
- exact `taskId + dispatchId` completion authority
- exact worktree-local JSON report contract
- non-consuming parallel `orchestration check --all --wait`
- read-only Orca live preflight
- Orca configuration example and Korean/English operations guides
- Orca contract, adversarial, and independent CLI black-box verification
- archive-safe JavaScript CLI shim launching that does not depend on executable permission bits

## Security defaults

- adapter disabled by default
- Manual Agent Permissions operator confirmation required
- explicit Orca repo selector required before dispatch
- mutation disabled before supervised live canary
- ProofGraph Workspace Engine and Orca worktree cannot both own isolation
- stale/duplicate/wrong-dispatch completion rejected
- report traversal, mismatch, symlink, malformed, missing, and oversized files rejected

## Release gate

`PASS_OFFLINE_ORCA_LIVE_CANARY_REQUIRED`

This release does not claim strict Orca-native state ownership, Remote/SSH worktree support, or production-safe mutation.
