# ProofGraph v0.8.0 — Approval-gated Workspace Execution

## Delivered

- Disposable detached Git worktree per Graph run.
- Workspace state digests and hashed execution receipts.
- Typed action protocol: `write_file`, `delete_file`, `apply_patch`, `run_command`.
- Challenge-bound human approval before any proposed action is executed.
- `git apply --check` preflight, safe relative paths, `.git` denial, and symlink traversal checks.
- Shell-free command execution with a command allowlist, timeout, output limits, and scrubbed environment.
- Automatic rollback on failed action batches.
- Detection and rollback of direct adapter mutations outside the action protocol.
- CLI lifecycle: create, propose, approve/deny, execute, diff, rollback, close.

## Security boundary

A Git worktree isolates changes from the primary checkout but does **not** provide network, process, credential, or kernel isolation. Live coding-agent profiles that can execute arbitrary tools still require an external container/micro-VM policy for stronger isolation. ProofGraph reports `network_isolated: false` rather than making a stronger claim.

## Verification

- Full suite: 121/121 PASS
- Adversarial cases cover traversal, `.git`, symlink, command allowlist, action-digest tampering, state tampering, and unauthorized direct mutation.
