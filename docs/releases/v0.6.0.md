# ProofGraph v0.6.0 — Universal Runtime Kernel

v0.6 separates graph orchestration from the Claude Code UI. It adds a standalone kernel, typed agent contracts, adapter registry/router, deterministic context envelopes, and a `proofgraph` CLI. The existing Claude plugin remains compatible.

Exit gate:

- Graph compiler/runtime can be driven without Claude Code.
- Adapter errors are persisted as typed failures.
- Offline mock adapter reaches verified terminal states.
- Existing v0.5 tests remain green.
